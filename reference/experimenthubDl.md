# Download files from ExperimentHub

Get the a dataset from ExperimentHub

## Usage

``` r
experimenthubDl(ID, cachePath)
```

## Arguments

- ID:

  The ID, a string, with "EH" followed by a series of numbers (e.g.
  EH119)

- cachePath:

  The path to store the downloaded file.

## Value

The path to the downloaded file.
