# Download files from Zenodo

Get a dataset from Zenodo

## Usage

``` r
zenodoDl(ID, cachePath)
```

## Arguments

- ID:

  The ID, a string, with D.O.I., optionally followed by a / and a file
  name.

- cachePath:

  The path to store the downloaded file.

## Value

The path to the downloaded file or containing folder if multiple files.
