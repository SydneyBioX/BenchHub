# Build a Dataset submission row from a Trio object

This helper is the first step in the new submission workflow. It does
not upload anything and does not modify the existing writeCTD() path.

## Usage

``` r
buildDatasetSubmission(
  trio,
  name = private_submission_dataset_name(trio),
  dataType,
  dataModality,
  technology,
  description = trio$description,
  doi = NA_character_,
  organism = NA_character_,
  tissue,
  status
)
```

## Arguments

- trio:

  A `Trio` object.

- name:

  Dataset name for submission. Defaults to the existing Trio name,
  falling back to `trio$dataSourceID` when needed.

- dataType:

  One of `"omics"` or `"clinical"`.

- dataModality:

  One of `"genomics"`, `"transcriptomics"`, `"epigenomics"`,
  `"proteomics"`, `"metabolomics"`, `"patient"`, or `"other"`.

- technology:

  Free-text technology description.

- description:

  Dataset description. Defaults to `trio$description` if present.

- doi:

  DOI reference for the dataset.

- organism:

  Free-text organism label.

- tissue:

  Free-text tissue label.

- status:

  One of `"healthy"`, `"diseased"`, `"developmental"`, or `"other"`.

## Value

A one-row `data.frame` matching the proposed `Dataset` table schema.
`datasetID` is left as `NA` because it is expected to be generated by
the submission backend.

## Examples

``` r
trio <- BenchHub:::private_example_submission_trio()
#> Error: object 'private_example_submission_trio' not found
buildDatasetSubmission(
  trio,
  dataType = "omics",
  dataModality = "transcriptomics",
  technology = "RNA-seq",
  tissue = "blood",
  status = "healthy"
)
#> Error: object 'trio' not found
```
